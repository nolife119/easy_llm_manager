시험할 기준 설정
기준 프리셋은 가속 시험 준비용입니다. GPU 번호·엔진·모델 저장 경로 및 접속 설정은 유지합니다.


1. 엔진에서 가능한 가속 기술 확인
현재 엔진의 --help를 검사합니다.
지원 표시가 있어도 모델별 동작은 실제 초기화와 생성으로 확인해야 합니다.


2. 속도 자동 비교




기준 → 지원되는 N-gram 방식 → GPU 샘플링 → 조합. 각 후보를 독립적으로 구동하고 코드 / 일반 입력을 비교합니다.
서버를 중지한 상태에서 실행합니다. 후보별 모델 재로딩이 필요합니다. 시험 종료 후 운영 서버는 자동 시작하지 않습니다.


3. 실제 결과
아직 측정하지 않았습니다.
두 작업의 출력이 greedy 기준에서 일치한 후보만 추천합니다. 목표 50 t/s는 보장값이 아니며, 실제 코딩 성능과 장문 품질은 별도 검증이 필요합니다.
