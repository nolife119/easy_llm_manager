Claude Code 연결

llama-server가 직접 Anthropic Messages API를 제공할 경우 로컬에 직접 연결합니다. 프록시는 사용하지 않습니다. 실제 Claude Code 통합은 Windows에서 확인해야 합니다.

엔진에 따라 /v1/messages 지원 여부가 다릅니다. 기능 검증의 Anthropic 항목을 확인하세요. 기존 Claude Code 로그인 환경에서 API 키/인증 설정 충돌이 있을 수 있습니다.
